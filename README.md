# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Files

- `index.html` - Game structure
- `style.css` - Game design and styling
- `script.js` - Game logic
- `README.md` - Project information

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Player X starts the game.
4. Players take turns clicking an empty box.
5. The first player to get three symbols in a row wins.
6. If all boxes are filled without a winner, the game is a draw.
7. Click **Restart Game** to play again.

## Technologies Used

- HTML
- CSS
- JavaScript
